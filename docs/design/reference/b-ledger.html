design direction B · reference sheet

Ledger

The app feels like a buffer in Jorge's editor. It's a dense, keyboard-first list, with time in a gutter and folds for each section. A statusline always says where you are. Nothing animates except the cursor, so it feels instant.

CONCEPT

LazyVim for notes: one list, folds, a cursor, a statusline and a which-key panel.

TYPE

JetBrains Mono for everything structural; IBM Plex Sans only for what a human wrote (titles and bodies).

SIGNATURE

The amber NOW line. It's reserved for the current time and splits what's past due from what's coming.

DARK MODE

Dark is home. Light mode is "the same ledger, printed": warm paper, the same ink and gutter.

Rules

  • Accent: amber is only the NOW line. Overdue isn't red: it's simply above the line.
  • Motion: none, except the cursor moving between rows (instant) and the caret blink in capture mode.
  • Reduced motion: the caret stops blinking. Nothing else changes.
  • Targets: every row is 44 px tall, so mouse and touch users get full-width hit areas.
  • Keyboard: the which-key panel is always visible on desktop. On mobile it collapses behind ?.
  • Density: about 14 rows per laptop screen, the densest of the three directions.
  • Risk: too "developer" for non-developers, and the paper warmth is weaker than in A or C.
